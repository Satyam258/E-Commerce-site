🐇 Rabbit – E-commerce Website

Rabbit is a modern full-stack E-commerce web application that allows users to browse products, manage carts, place orders, and make secure payments.
Built with the MERN stack and enhanced with PayPal integration, Cloudinary for media, and TailwindCSS for sleek UI, Rabbit delivers a seamless shopping experience.

🚀 Features
👤 User Features

🔐 User authentication & authorization (JWT-based)

🛍️ Browse and search products

🛒 Add to cart & manage items

💳 Checkout with PayPal integration

📦 Order tracking & history

🛠️ Admin Features

📦 Manage products (CRUD operations)

👥 Manage users

📊 View all orders & update statuses

☁️ Product image uploads with Cloudinary

🏗️ Tech Stack
Frontend (React + Vite)

⚛️ React 19 + Vite

🎨 TailwindCSS v4 + React Icons

🛠️ Redux Toolkit for state management

🌐 React Router v7

💳 PayPal React SDK

🔔 Sonner for notifications

Backend (Node + Express + MongoDB)

🖥️ Express.js server

🗄️ MongoDB + Mongoose ORM

🔐 JWT for authentication

🔑 bcrypt.js for password hashing

☁️ Cloudinary + Multer for image uploads

🔄 Nodemon for development

🌍 CORS for cross-origin requests

📂 Project Structure
Rabbit/
│── frontend/     # React + Vite frontend
│── backend/      # Express + MongoDB backend
│── README.md     # Project documentation

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/yourusername/rabbit.git
cd rabbit

2️⃣ Backend Setup
cd backend
npm install

3️⃣Create a .env file in the backend folder:

-> PORT=5000
-> MONGO_URI=your_mongodb_connection_string
-> JWT_SECRET=your_jwt_secret
-> CLOUDINARY_CLOUD_NAME=your_cloud_name
-> CLOUDINARY_API_KEY=your_api_key
-> CLOUDINARY_API_SECRET=your_api_secret
-> PAYPAL_CLIENT_ID=your_paypal_client_id

4️⃣Run the backend:
-> npm run dev

5️⃣Frontend Setup
-> cd frontend
-> -npm install


Create a .env file in frontend:

-VITE_API_URL=http://localhost:5000


-Run the frontend:

-npm run dev
